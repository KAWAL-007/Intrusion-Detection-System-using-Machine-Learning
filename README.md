# 🔐 Intrusion Detection System using Machine Learning

## 📌 Overview

This project presents a Machine Learning-based Intrusion Detection System (IDS) designed to identify malicious network activity. It analyzes network traffic data and classifies it as normal or attack, helping improve cybersecurity and threat detection.

---

## 🚀 Features

* 🤖 Machine Learning model (Random Forest)
* 📊 Interactive dashboard using Streamlit
* 📈 Multiple data visualizations (10+ graphs)
* 🔍 Real-time intrusion detection (based on dataset)
* 🌐 Deployable as a web application

---

## 🧠 Technologies Used

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib, Seaborn
* Streamlit

---

## 📂 Dataset

* NSL-KDD Dataset
* Contains network traffic data with multiple features and attack labels

---

## ⚙️ How It Works

1. Data preprocessing and encoding
2. Feature selection and training
3. Model building using Random Forest
4. Prediction of normal vs attack traffic
5. Visualization of results using graphs

---

## 📊 Visualizations Included

* Label Distribution
* Correlation Heatmap
* Confusion Matrix
* Feature Importance
* Histogram
* Box Plot
* Scatter Plot
* Count Plot
* Distribution Plot
